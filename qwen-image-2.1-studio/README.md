# qwen-image-2.1-studio

## 项目名
**qwen-image-2.1-studio**

## 介绍 / 能力
面向 **Apple Silicon** 的本地 Qwen-Image-2.1 工作室：离线文生图、多图编辑、提示词增强，提供 CLI 与 helmstudio Web UI，基于 PyTorch / MPS，注重隐私、无需上传云端。

- 分类：本地生图 ｜ Apple Silicon 本地生图
- 语言：Python ｜ 默认分支 main ｜ Star（快照）~60
- 关键词：apple-silicon · mps · qwen-image · text-to-image · image-editing · local-ai · web-ui

## 适用场景
Mac 上离线生图与多图编辑、隐私敏感的出图任务、本地模型工作流。
