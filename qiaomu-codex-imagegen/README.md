# qiaomu-codex-imagegen

## 项目名
**qiaomu-codex-imagegen**（乔木 · Codex 生图）

## 介绍 / 能力
让**任意 Agent**（Claude Code、Cursor 等）调用 Codex 内置生图能力，提供 MCP 服务、命令行、Agent Skill 三种接入方式；一句话即可出小红书配图。每次生图先给出至少四种机制不同的风格方向供选定，再出图，内置小红书、视频封面、Mondo 海报等场景模板技巧。

- 分类：生图 Agent ｜ 一句话拿到小红书配图
- 语言：JavaScript ｜ 默认分支 main ｜ Star（快照）~130
- 关键词：codex · image-generation · mcp · agent-skills · xiaohongshu · poster-design
- 作者：joeseesun（向阳乔木）

## 适用场景
小红书配图、视频封面、Mondo 风格海报，在常用 Agent 里直接出图。
