# hyperframes

## 项目名
**hyperframes**（HeyGen 出品）

## 介绍 / 能力
**写 HTML 就能出视频**，面向 Agent 的动效视频框架。用 HTML/GSAP 描述画面与动画，经 Puppeteer 渲染、FFmpeg 合成输出视频，内置 MCP，让 Agent 直接生成产品发布/宣传动效视频。

- 分类：动效视频 ｜ 写 HTML 就能出视频
- 语言：TypeScript ｜ 默认分支 main ｜ Star（快照）~67k
- 技术栈：HTML · GSAP · Puppeteer · FFmpeg · MCP

## 适用场景
产品发布视频、宣传片、营销动效、Agent 自动生成视频。
