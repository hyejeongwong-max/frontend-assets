# mesh-avatar-studio

## 项目名
**mesh-avatar-studio**

## 介绍 / 能力
**一张插画变成可动的 2D mesh 立绘**：配合 coding Agent 与本地编辑器，把静态插画做网格变形（mesh deformation），生成可动的 VTuber 风格 2D 头像/立绘（WebGL）。

- 分类：IP 动画 ｜ 一张插画变可动立绘
- 语言：TypeScript ｜ 默认分支 main ｜ Star（快照）~850
- 关键词：2d-animation · mesh-deformation · avatar · vtuber · webgl · claude-code · codex

## 适用场景
静态插画转动效立绘、虚拟头像/VTuber 原型、IP 角色动态化。
