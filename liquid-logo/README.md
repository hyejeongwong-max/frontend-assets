# Liquid Logo

## 项目名
**liquid-logo**（paper-design）

## 介绍 / 能力
用 **Paper Shaders** 把普通 Logo 变成流动的**液态金属**质感，可在线直接生成，无需写代码。

- 分类：金属 Logo
- 语言：TypeScript ｜ 默认分支 main ｜ Star（快照）~1.3k
- 在线工具：https://liquid.paper.design

## 上手
打开在线工具 https://liquid.paper.design ，上传/输入 Logo 即可生成液态金属演绎；仓库提供底层 Paper Shaders 实现。

## 适用场景
品牌开场动画、加载页、金属质感 Logo 演绎、片头。
