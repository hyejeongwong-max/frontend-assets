# spotkit

## 项目名
**spotkit**

## 介绍 / 能力
一个 Claude Code Skill，把**功能描述秒变成极简、抽象的 SVG 产品插画**，且所有插画属于同一套设计系统。适合 SaaS 空状态、功能介绍、配图，风格统一、可直接内联进页面。

- 分类：平面插画 ｜ 功能描述秒变 SVG 插画
- 语言：HTML ｜ 默认分支 main ｜ Star（快照）~85
- 关键词：svg-illustrations · design-system · product-illustration · claude-skill · generative-design

## 适用场景
产品功能配图、空状态插画、统一风格的 SVG 图标集。
