# oil-ui

## 项目名
**oil-ui**（Oil UI）

## 介绍 / 能力
给 AI Agent 用的 **UI 设计 Skill**，让 Agent 学会审美。先理解产品定位与对标风格，把"高级/干净"这类空词落成具体决策（字体、留白、用色比例）；并排探索几个真正不同的设计方向供你挑选，再对照桌面/移动真实截图打磨、做减法。适用于网站、App、仪表盘与组件。

- 分类：UI 设计 ｜ 让 Agent 学会审美
- 语言：Python ｜ 默认分支 main ｜ Star（快照）~1.8k ｜ License MIT
- 作品站：https://ui.oiloil.org

## 上手
```bash
npx skills add oil-oil/oil-ui
```
装好后直接让 Agent："用 oil-ui 为这个课程预订产品探索几个设计方向，并生成可预览页面。"

## 适用场景
从零出设计稿、多方向比选、按现有规范打磨页面、按截图复刻并补移动端。
